# hexfylios-research
An open-source deep research agent specialised for securities markets, that can be deployed anywhere.

## Roadmap

- Support for clarifying questions based on the query before starting with the deep research.
- ResearchManager agent turns into an agent with agents-as-tools (using Search and Planner as tools), so that the manager can perform more searches and refinements to the report.
